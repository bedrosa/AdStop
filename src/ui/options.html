Plataformas de streaming

Estos controles activan las funciones de bloqueo de cada plataforma. Para permitir todos los anuncios de una web, usa el botón principal de AdStop en esa página. Los anuncios integrados en el vídeo pueden seguir apareciendo.

Excepciones

Los cambios se aplican al guardar. Después, recarga las webs abiertas.

Listas de filtros

Las listas se incluyen en la extensión y se renuevan al actualizarla. No se descarga código durante la navegación.
